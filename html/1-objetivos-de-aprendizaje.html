Técnicas y procesos de extracción de información

1. Objetivos de aprendizaje

Al finalizar este tema, serás capaz de:

  • Comprender qué significa extraer información de datos estructurados, semiestructurados y no estructurados.
  • Identificar y describir las principales técnicas de extracción de datos:
    • Consultas a bases de datos (SQL).
    • APIs.
    • Web scraping.
    • Minería de texto.
  • Entender por qué la extracción de datos es solo el primer paso y por qué es tan importante la fase de limpieza y preparación (data wrangling).
  • Aplicar procesos básicos de:
    • Limpieza de datos (corregir errores, eliminar duplicados).
    • Normalización de formatos (fechas, textos, números).
    • Transformación de datos (crear nuevas columnas, recodificar valores).
  • Implementar un pequeño flujo de trabajo completo de datos usando herramientas accesibles:
    • Desde un fichero CSV o una API.
    • Pasando por la limpieza en Excel o Python.
    • Dejando los datos listos para un análisis sencillo (por ejemplo, una tabla dinámica o un gráfico).
