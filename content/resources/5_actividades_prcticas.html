5. Actividades prácticas

Actividad 1 – Limpieza de Datos con Pandas

Material

El fichero de datos para esta actividad (clientes_actividad.csv) está alojado en un repositorio de GitHub.

URL RAW (Cruda) de los datos: https://raw.githubusercontent.com/josedavidmi/iabd-sbd/refs/heads/main/clientes_actividad.csv

Tareas del Alumnado

El objetivo es cargar el fichero de datos, limpiarlo y generar un informe resumen.

1. Carga de Datos (Extracción)

  1. Abre un nuevo cuaderno de Google Colab.
  2. Importa las librerías pandas.
  3. Carga el fichero clientes_actividad.csv directamente desde la URL RAW de GitHub en un DataFrame llamado df.

2. Limpieza de Datos (Data Wrangling)

Advertencia: Los datos contienen duplicados y errores de formato.

  1. Eliminar Duplicados:
    1. Detecta y elimina los registros que están completamente duplicados (comparando todas las columnas).
    2. Usa el método .drop_duplicates() de Pandas.
  2. Corregir Errores de Escritura (Normalización):
    • Identifica los errores de escritura en la columna ciudad (Madird, Mdrid, Valenca, Barcleona).
    • Usa el método .replace() o .loc[] de Pandas para unificar todos los nombres incorrectos al nombre correcto (Madrid, Valencia, Barcelona, etc.).
  3. Unificar el Formato de Fechas:
    • La columna fecha_registro tiene varios formatos (guiones, barras, año completo, año corto).
    • Convierte toda la columna al tipo de dato datetime de Pandas (usando pd.to_datetime()).
    • Una vez convertida, aplica el formato estándar DD/MM/AAAA (Día/Mes/Año) para mostrarla de forma unificada (usando el método .dt.strftime()).

3. Generación del Informe (Resumen)

  1. Crea una tabla resumen que muestre: el número total de clientes por cada ciudad.
  2. Para esto, utiliza una combinación de los métodos .groupby() y .count() o el método .value_counts() de Pandas.

Objetivo de la actividad

  • Comprender que la limpieza y normalización es el paso más crítico tras la extracción de datos en bruto.
  • Practicar las funciones esenciales de limpieza de datos en la herramienta estándar de Python para Data Science: Pandas.
  • Generar un resumen analítico simple a partir de datos limpios.

Actividad 2 – Uso de una API pública (nivel básico con JSON)

Contexto
En esta actividad, simularás la tarea de un analista que necesita obtener el pronóstico de la temperatura horaria para una ciudad específica (por ejemplo, Castro Urdiales), accediendo a una API profesional de datos meteorológicos.

 Material

  • Cuaderno de Google Colab.
  • Acceso a la API pública de Open-Meteo.
  • Librerías de Python: openmeteo_requests, pandas, requests_cache, y retry_requests. 

Tareas del Alumnado
El objetivo es extraer la temperatura horaria del día de hoy y transformarla en un formato de tabla utilizable.

1. Preparación y Extracción (API)

  1. Configura el cliente de la API en Colab (tal como se ha visto en clase), implementando la caché y los reintentos (retry) para garantizar una extracción eficiente y fiable.
  2. Define los parámetros de la consulta para obtener los siguientes datos para Santander (Latitud : 43.440829950828544, Longitud : -3.8223838944785076):
    • Pronóstico horario de la variable temperature_2m.
    • El pronóstico debe limitarse a 1 día (forecast_days: 1).
  3. Ejecuta la solicitud a la API y almacena la respuesta.

2. Transformación de Datos (Pandas)

  1. Accede a la parte de la respuesta que contiene los datos horarios (response.Hourly()).
  2. Extrae por separado:
    • La serie de tiempo (las marcas de tiempo para cada hora).
    • Los valores de temperatura (temperature_2m).
  3. Crea un DataFrame de Pandas que combine estas dos extracciones en columnas separadas: Hora y Temperatura (°C).
    • Pista: Asegúrate de que las marcas de tiempo se conviertan correctamente a fechas y horas legible usando pd.to_datetime().

3. Conclusión (Análisis)

  1. Una vez creado el DataFrame, utiliza Pandas para responder a la siguiente pregunta:
    • ¿Cuál es la temperatura máxima (max()) y la temperatura mínima (min()) pronosticadas para el día de hoy?
  2. Imprime el DataFrame completo y las temperaturas máximas y mínimas encontradas.

Objetivo de la actividad

  • Comprender el flujo de trabajo completo: Configuración de cliente → Extracción de datos JSON desde la API → Transformación a un DataFrame.
  • Practicar la desestructuración de datos semiestructurados.
  • Aplicar funciones básicas de resumen (max, min) sobre un conjunto de datos transformado.
